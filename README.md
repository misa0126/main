# ゆっくり解説 素材自動収集ツール

台本テキストを渡すと、シーンごとにClaude APIでキーワードを抽出し、Google画像検索から候補画像を
ダウンロードして自動選別するコマンドラインツールです。

## 重要: 著作権に関する注意

Google画像検索の結果には、著作権で保護され再利用が許可されていない画像が多数含まれます。
このツールは検索結果ページから画像を機械的に取得するだけで、**個々の画像の利用ライセンスを
確認・保証するものではありません**。

- ダウンロードした画像をそのまま動画に使用せず、**投稿前に出典・ライセンスを個別に確認**してください。
- 収益化(広告収入化)しているチャンネルで使用する場合は特に注意してください。著作権者から
  申し立てを受けたり、動画が収益化停止・削除になるリスクがあります。
- 大量・自動的なアクセスはGoogleの利用規約に抵触する可能性があります。個人利用の範囲で、
  常識的な頻度・件数で使用してください。
- 権利関係を気にせず使いたい場合は、Pexels / Pixabayなど再利用ライセンスを明示した無料素材APIの
  利用を推奨します。

以上を理解した上での自己責任利用を前提としたツールです。

## セットアップ

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # ANTHROPIC_API_KEY を設定
export ANTHROPIC_API_KEY=sk-ant-...
```

## 台本フォーマット

シーンの区切りを **空行** で表します。

```
霊夢「今日は東京タワーについて解説するのよ」
魔理沙「東京タワーは1958年に完成した電波塔だぜ」

霊夢「高さは333メートルもあるのよ」
魔理沙「当時は世界一高い自立式鉄塔だったんだぜ」
```

上記は2シーンとして扱われます。サンプルは `examples/sample_script.txt` にあります。

## 使い方

```bash
python main.py examples/sample_script.txt -o output
```

主なオプション:

| オプション | デフォルト | 説明 |
|---|---|---|
| `-o, --output` | `output` | 出力先ディレクトリ |
| `--keywords-per-scene` | `3` | シーンごとに生成する検索キーワード数 |
| `--candidates-per-keyword` | `8` | キーワードごとにダウンロードする候補数 |
| `--images-per-scene` | `3` | シーンごとに最終選別する画像数 |
| `--min-width` / `--min-height` | `400` / `300` | 選別する画像の最小サイズ(px) |
| `--model` | Claude Haiku | キーワード抽出に使うClaudeモデルID |
| `--keep-candidates` | オフ | 選別前の候補画像もすべて保存する |

## 出力構造

```
output/
  manifest.json          # 全シーンの台本・キーワード・選別画像の対応表
  scene_001/
    keywords.txt         # 生成された検索キーワード
    selected/             # 選別された画像
      001.jpg
      002.jpg
    candidates/           # --keep-candidates 指定時のみ、選別前の全候補
  scene_002/
    ...
```

`manifest.json` を見れば、どのセリフからどの画像が選ばれたかを一覧できるので、
動画編集ソフトに素材を割り当てる際の作業台帳として使えます。

## 選別ロジック

1. 破損・読み込み不能な画像を除外
2. `--min-width` / `--min-height` 未満の低解像度画像を除外
3. 知覚ハッシュ(pHash)でシーン内の類似画像・重複画像を除外
4. 検索結果の上位から `--images-per-scene` 枚に達するまで採用

## 制限事項

- Google画像検索の非公式スクレイピング(`icrawler`)を利用しているため、Google側の仕様変更で
  取得件数が減ったりエラーになったりすることがあります。
- 短時間に大量のシーン・キーワードを処理すると、Google側から一時的にブロックされる可能性があります。
