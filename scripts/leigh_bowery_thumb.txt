# 動画タイトルは「タイトル｜名前【ゆっくり生涯解説】」の形。職業・肩書きと有名な相手(フロイド・マックイーン・ボーイ・ジョージ)が分かる15文字くらいにし、サムネの一言と同じことを言わない
# 一言はユーザーの11か条(CLAUDE.md): 8〜12文字・人名なし・台本の事実だけ・「なんで！？」と思わせる・下げない・全部は疑問文にしない・1秒で読める
# 3案とも顔アップ(いつもの型)で、上の一言だけ変える。方向は「意外な正体」(派手に着飾ったロンドンの夜の怪人、という見え方をひっくり返す)
#   案1: 最後まで病を隠した芸術家(12字)… HIVを親しい人にしか打ち明けず、最後まで隠し通した。「エイズの人ではなく、アイデアを持った人間として記憶されたい」(台本244〜252行・398〜409行)
#   案2: 着飾る男が裸で名画に(10字)… 命がけで着飾れと言った男が、フロイドの絵では何も身に着けず描かれ、メトロポリタン美術館が買い上げた(台本11〜14行・255〜303行)
#   案3: 本当は内気な夜の帝王(10字)… フロイドは、リーは本当は内気でとても穏やかな男で、派手な姿は身を守る鎧だったと見ていた(台本271〜275行)
# いちばんのおすすめ: 案2(この強烈な化粧の顔と「裸で名画に」の落差が1秒で伝わり、「着飾る男がなぜ？」と思わせる。台本の冒頭の掴みそのものなので、動画の芯とも合う)
