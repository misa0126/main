# 動画タイトルは「タイトル｜名前【ゆっくり生涯解説】」の形。肩書き(SF作家・伝奇作家)と代表作(『戦国自衛隊』『妖星伝』)が分かる15文字くらいにし、サムネの一言と同じことを言わない
# 一言はユーザーの11か条(CLAUDE.md): 8〜12文字・人名なし・台本の事実だけ・「なんで！？」と思わせる・下げない・全部は疑問文にしない・1秒で読める
# 3案とも顔アップ(いつもの型)で、上の一言だけ変える。方向は「意外な正体」(『戦国自衛隊』のSF作家・直木賞作家、という見え方をひっくり返す)
#   案1: 直木賞作家は元バーテン(11字)… 作家になる前に30近い職業を渡り歩き、バーテンダーとして店の経営まで任されていた。受賞作『雨やどり』もバーテンダーが主人公(台本74〜105行・266〜288行)
#   案2: 直木賞はSFじゃなかった(12字)… SF作家として初めて直木賞を獲ったが、受賞作はSFではなく新宿の裏通りのバーの人情小説だった(台本9〜13行・279〜282行)
#   案3: 80巻予定、18巻で未完(12字)… ムー大陸の2000年を描く全80巻の『太陽の世界』は、18巻で止まり未完のまま残った(台本333〜406行)
# いちばんのおすすめ: 案1(「直木賞作家」という立派な肩書きと「元バーテン」の落差が1秒で伝わり、「なんで？」と思わせる。夜の街で人を見続けた経験が受賞作になった、という人生の芯そのもの)
# 顔の大きさは「アップ」: 作家で、目つきと表情が印象的な人なので、スマホでも目が読めるように寄せる
# 表情: 案1・案2は自動(霊夢 驚き・魔理沙 にやり。意外な正体に合う)。案3は書き切れなかった大作の話なので、魔理沙の「にやり」を「焦り」にした
# 写真はカラー: ユーザーが送った写真がカラーで、紺の着物と書斎の木の色が昭和の作家らしさを出しているため。白黒写真しかない昔の人ではない
