#   説明しない・すごさを大きな言葉で言い切る・引っかかりは小さな具体1つだけ。動画タイトルは「タイトル｜名前【ゆっくり生涯解説】」で、サムネと同じことを言わない
#   案1: ウォーホルに影響を与えた天才(13字)… 草間の柔らかい立体作品は、のちに大スターになるウォーホルやオルデンバーグにも影響を与えた(台本275〜277行)。建畠晢は草間を「天才」と語った(台本450行)。有名な相手を引っかかりにする(乱歩・ガガと同じ)
#   案2: 恐怖を水玉で塗りつぶした(12字)… 水玉と網は子どもの頃から見えていた怖い幻覚を描き写したもので、描くことで恐怖に打ち勝とうとした(台本84〜92・268〜270行)。誰でも知っている水玉の正体を言い切る
#   案3: 無断で乗りこみ国の代表に(12字)… 1966年、招待もないのにヴェネツィア・ビエンナーレに乗りこみ、1993年には日本代表として同じ場所に戻った(台本337〜338・502〜512行)。お手本の「嫌いな名前で天下を取った」と同じく、小さな引っかかり+大きな結末
#   落とした惜しい候補: 「幻覚を世界の宝にした天才」/「入ると自分が消える部屋」(自己消滅、台本319〜331行)/「飛び出した故郷が美術館に」
# いちばんのおすすめ: 案2(誰でも知っている可愛い水玉が「恐怖を塗りつぶした」ものだと言い切るので、名前を知らなくても写真の水玉とつながって1秒で「え？」となる。草間の人生の芯の話)
# 写真: 水玉の背景に赤いおかっぱ・赤い服の、正面を向いたカラー写真(顔が大きく写っているもの)。おかっぱと水玉が目印なので顔の大きさは「大」、カラー
# 表情: 案1・案3は自動(霊夢 驚き・魔理沙 にやり)。案2は「恐」で自動だと焦り・驚きになるが、恐怖に打ち勝った話なので 驚き・にやり にした
