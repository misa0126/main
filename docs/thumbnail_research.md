# ゆっくり解説のサムネ調査(2026年11月)

> **大事: 「ゆっくり人物歴史学」はユーザー本人のチャンネル。** 下の「1. 顔アップ型」はユーザーのいまの型で、
> その型でクリック率は1〜3%。なので顔アップ型は「伸びる型」ではなく「比べる基準」として扱う。
> 改善の方向は、後半の「ゆっくり解説全体で最近伸びている型」(2回目の調査)を見ること。

YouTubeで「ゆっくり解説」「ゆっくり解説 生涯」「ゆっくり歴史解説 人物 生涯」「ゆっくり解説 棋士」などを
再生回数順・関連度順・今年に絞って検索し、約500本から人物の生涯系を中心に約40本のサムネを見比べた。
(クリック率そのものは外から見えないので、再生回数と投稿からの日数で「伸びている」と判断した)

## 見つかったこと

1. **人物の生涯系でいちばん多い勝ちパターンは「顔アップ」型**
   - 本人の顔を画面いっぱい(目が見える大きさ)。白黒にしてコントラストを強くする
   - 上に **赤い文字・白ふち** の一言、下に **黄色の大きな名前**(姓と名の間に空白)
   - ゆっくりは四隅に小さく(ジャンルの目印。大きくしなくてよい)
   - 例: ゆっくり人物歴史学(寺田ヒロオ 26万、さくらももこ 16万、村山聖 9万 など。同じ型で量産)

2. **上の一言は「実績」ではなく「え、なんで？」と思わせる一言**
   - 伸びた例: 「全員育てて自分だけ消えた」「病を誰にも言わず描き続けた」「本当の正体を誰も知らない」
     「税金滞納王が日本一の納税者に」「若い頃は雑魚と呼ばれていた男」「ノーベル賞の後に勲章を断った」
   - 形: 「〜した男」「〜なのに〜」(落差)、「正体」「誰も知らない」「なぜ〜のか」(謎)
   - 同じ型・同じチャンネルでも、再生回数は一言の強さと人物の知名度で10倍以上ちがう

3. **将棋の視聴者には「黒地に白い大きな文字だけ」も伸びている**
   - 将棋情報そら: 「大山康晴 残虐すぎる」10万、「これは残酷すぎる…」9万(写真なし・ゆっくりなし)
   - 感情の強い言葉(残虐・残酷・ヤバすぎる・嫌われる)+人名

4. **ほかに伸びている型**
   - 名前を極太の大きな字で(ゆっくり日本の近現代史: 明治天皇 61万、田中角栄 46万)。ゆっくりは中くらい
   - 暗い背景に人物+強い言葉(闇の歴史ツアー: 「地獄の代償」松井須磨子 86万)
   - 「〜選」のまとめ物は再生数が大きいが、生涯解説とは別の型

5. **型をはずして当たることもある**: 同じチャンネルでいちばん伸びた「クラウス・ノミ」(114万)は、白黒をやめて
   カラーの宇宙背景、ゆっくりも大きく驚き顔。見た目が強い人物なら型をくずす案も試す価値がある

## サムネ作成ページでの使い方

- 案1・案2は「顔アップ」型で、一言を変えて「テストと比較」で比べる
- 案3は「文字だけ」型や「右に写真」型など、型そのものを変えて比べる
- 一言は台本の冒頭の掴み(導入)から取るとよい。事実と合わない煽りは書かない

## 2回目の調査: 「ゆっくり解説」全体で最近伸びている型

「ゆっくり解説」「ゆっくり歴史解説」などを、今月・今年に絞って再生回数順に検索し、ここ1〜3か月で数十万〜100万回を
超えた動画のサムネを見た(世界史裏探訪、キンブラ、よつばch、いろはCH、おやすみ歴史館、あっと驚く経済学 など)。
ユーザーのチャンネルのサムネと比べて、ちがいは次のとおり。

1. **いちばん大きい字が「名前」ではなく「話の落差・オチ」**
   - 伸びている例: 下に大きく「トラウマ体験すぎる…」「『破門』が怖すぎる」「処刑に散った皇族」「平安のヤバすぎる真実」
   - ユーザーのサムネは下半分を名前が占める。名前を知らない人には、いちばん大きい情報が「知らない名前」になってしまう
   - → 大きい字は落差(「それでも将棋界の王に」)、名前は小さく(またはタイトルに任せる)
2. **カラーで、場面が見える**
   - 絵巻・絵画・現場写真などをカラーで使い、何が起きたかが一目で分かる。白黒の顔写真だけのものは少ない
   - ユーザーのチャンネルでいちばん伸びたクラウス・ノミ(114万)もカラーで、型をくずしたサムネだった
3. **セリフの吹き出しで感情を見せる**
   - 「じゃあなんでそんな強ぇんだよ…」「餓死しちまうぞ」「お前ら何者？」など、見ている人の気持ちを代わりに言う
   - キャラ(ゆっくり・ずんだもん)は大きめで、驚き・焦りなどの表情。ユーザーのサムネのゆっくりは小さく、ふつうの顔
4. **文字は2段・2色まで**: 上に黄色か白の短い一言、下に赤(白ふち)の大きなオチ。文字の量は少ない
5. **タイトルも一緒に変える**: 伸びている動画のタイトルは「なぜ〜のか？」「〜した結果」「〜すぎる」など問いかけや落差。
   ユーザーの「【ゆっくり生涯解説】名前｜肩書き」は、名前を知らない人がクリックする理由がない

→ サムネ作成ページの「型: 吹き出し」はこの型。案1をいまの型(顔アップ)、案2・案3を吹き出しの型にして、
  「テストと比較」でどちらが上か確かめる。
