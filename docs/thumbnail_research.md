# ゆっくり解説のサムネ調査(2026年11月)

> **大事: 「ゆっくり人物歴史学」はユーザー本人のチャンネル。** 下の「1. 顔アップ型」はユーザーのいまの型で、
> その型でクリック率は1〜3%。なので顔アップ型は「伸びる型」ではなく「比べる基準」として扱う。
> 改善の方向は、後半の「ゆっくり解説全体で最近伸びている型」(2回目の調査)を見ること。

YouTubeで「ゆっくり解説」「ゆっくり解説 生涯」「ゆっくり歴史解説 人物 生涯」「ゆっくり解説 棋士」などを
再生回数順・関連度順・今年に絞って検索し、約500本から人物の生涯系を中心に約40本のサムネを見比べた。
(クリック率そのものは外から見えないので、再生回数と投稿からの日数で「伸びている」と判断した)

## 見つかったこと

1. **人物の生涯系でいちばん多い勝ちパターンは「顔アップ」型**
   - 本人の顔を画面いっぱい(目が見える大きさ)。白黒にしてコントラストを強くする
   - 上に **赤い文字・白ふち** の一言、下に **黄色の大きな名前**(姓と名の間に空白)
   - ゆっくりは四隅に小さく(ジャンルの目印。大きくしなくてよい)
   - 例: ゆっくり人物歴史学(寺田ヒロオ 26万、さくらももこ 16万、村山聖 9万 など。同じ型で量産)

2. **上の一言は「実績」ではなく「え、なんで？」と思わせる一言**
   - 伸びた例: 「全員育てて自分だけ消えた」「病を誰にも言わず描き続けた」「本当の正体を誰も知らない」
     「税金滞納王が日本一の納税者に」「若い頃は雑魚と呼ばれていた男」「ノーベル賞の後に勲章を断った」
   - 形: 「〜した男」「〜なのに〜」(落差)、「正体」「誰も知らない」「なぜ〜のか」(謎)
   - 同じ型・同じチャンネルでも、再生回数は一言の強さと人物の知名度で10倍以上ちがう

3. **将棋の視聴者には「黒地に白い大きな文字だけ」も伸びている**
   - 将棋情報そら: 「大山康晴 残虐すぎる」10万、「これは残酷すぎる…」9万(写真なし・ゆっくりなし)
   - 感情の強い言葉(残虐・残酷・ヤバすぎる・嫌われる)+人名

4. **ほかに伸びている型**
   - 名前を極太の大きな字で(ゆっくり日本の近現代史: 明治天皇 61万、田中角栄 46万)。ゆっくりは中くらい
   - 暗い背景に人物+強い言葉(闇の歴史ツアー: 「地獄の代償」松井須磨子 86万)
   - 「〜選」のまとめ物は再生数が大きいが、生涯解説とは別の型

5. **型をはずして当たることもある**: 同じチャンネルでいちばん伸びた「クラウス・ノミ」(114万)は、白黒をやめて
   カラーの宇宙背景、ゆっくりも大きく驚き顔。見た目が強い人物なら型をくずす案も試す価値がある

## サムネ作成ページでの使い方

- 案1・案2は「顔アップ」型で、一言を変えて「テストと比較」で比べる
- 案3は「文字だけ」型や「右に写真」型など、型そのものを変えて比べる
- 一言は台本の冒頭の掴み(導入)から取るとよい。事実と合わない煽りは書かない

## 2回目の調査: 「ゆっくり解説」全体で最近伸びている型

「ゆっくり解説」「ゆっくり歴史解説」などを、今月・今年に絞って再生回数順に検索し、ここ1〜3か月で数十万〜100万回を
超えた動画のサムネを見た(世界史裏探訪、キンブラ、よつばch、いろはCH、おやすみ歴史館、あっと驚く経済学 など)。
ユーザーのチャンネルのサムネと比べて、ちがいは次のとおり。

1. **いちばん大きい字が「名前」ではなく「話の落差・オチ」**
   - 伸びている例: 下に大きく「トラウマ体験すぎる…」「『破門』が怖すぎる」「処刑に散った皇族」「平安のヤバすぎる真実」
   - ユーザーのサムネは下半分を名前が占める。名前を知らない人には、いちばん大きい情報が「知らない名前」になってしまう
   - → 大きい字は落差(「それでも将棋界の王に」)、名前は小さく(またはタイトルに任せる)
2. **カラーで、場面が見える**
   - 絵巻・絵画・現場写真などをカラーで使い、何が起きたかが一目で分かる。白黒の顔写真だけのものは少ない
   - ユーザーのチャンネルでいちばん伸びたクラウス・ノミ(114万)もカラーで、型をくずしたサムネだった
3. **セリフの吹き出しで感情を見せる**
   - 「じゃあなんでそんな強ぇんだよ…」「餓死しちまうぞ」「お前ら何者？」など、見ている人の気持ちを代わりに言う
   - キャラ(ゆっくり・ずんだもん)は大きめで、驚き・焦りなどの表情。ユーザーのサムネのゆっくりは小さく、ふつうの顔
4. **文字は2段・2色まで**: 上に黄色か白の短い一言、下に赤(白ふち)の大きなオチ。文字の量は少ない
5. **タイトルも一緒に変える**: 伸びている動画のタイトルは「なぜ〜のか？」「〜した結果」「〜すぎる」など問いかけや落差。
   ユーザーの「【ゆっくり生涯解説】名前｜肩書き」は、名前を知らない人がクリックする理由がない

→ サムネ作成ページの「型: 吹き出し」はこの型。案1をいまの型(顔アップ)、案2・案3を吹き出しの型にして、
  「テストと比較」でどちらが上か確かめる。

### ユーザーがいちばん好きな一言: 「本当は教え子より壮絶だった」(アン・サリバン 11万)

ユーザーの感想: 「え！？そうなの？ってなる」。
- 誰でも知っている話(ヘレン・ケラーの苦労)を土台にして、「じつは脇役のほうが上だった」とひっくり返している。
  名前を知らなくても、知っている話との比べ方だけで「え？」となる。
- 形: **「本当は(有名な相手・有名な話)より(意外な事実)だった」**。主人公の隣に有名人や有名な作品がいる人物で使える
  (師匠と弟子、コンビの片方、有名作品の原作者、有名人の家族など)。事実と合うときだけ使う。
- サムネ案を作るとき、この形が事実と合う人物なら、3案のうち1案に入れる。
- **毎回同じ言い方だと飽きる**(ユーザーの希望)。芯は「みんなが知っている話をひっくり返す」で、言い方は毎回変える:
  - 比べる: 「教え子より壮絶だった」「弟子より先に〜した」
  - 主役を入れかえる: 「〇〇を作ったのは別の男」「影の生みの親」
  - 知らない時代: 「10年売れなかった国民的作家」「〇〇の前は〜だった」
  - 結末をひっくり返す: 「2000万部売れて忘れられた」「〜なのに〜で終わった」
  - 知らない顔: 「〇〇の裏の顔」「〜とは別の顔」
  - 作品の出どころ: 「あの〇〇は〜から生まれた」
  - 役を入れかえる: 「嫌われ役が一番優しかった」
  直前に作った人物のサムネと同じ言い方にならないようにする。

### 伸びているのは人か、サムネか(2026年11月の見立て)

投稿から日が浅い3本を除いた247本で、再生数(対数)の差のうち、ジャンルで説明できるのは約36%、投稿時期を足して約50%。
残りの半分は同じジャンルの中の差(同じSF作家でも眉村卓0.55万・星新一12.6万、漫画家でも0.7万〜26万)。
→ **人(ジャンル)の影響がいちばん大きいが、それで決まるのは半分くらい**。残りは人物の知名度・人生の濃さと、サムネ・タイトル。
外からはクリック率が見えないので、サムネの効果だけは分けられない。YouTube Studio の
「インプレッション数」(=人物・関連動画でどれだけ出されたか)と「インプレッションのクリック率」(=サムネ・タイトルの力)で分けて見る。

  → 台本の質や掴みで差がついているのではない。クリック率もほぼ同じなので、**再生数の差は「人物(テーマ)にどれだけ見たい人がいるか」でほぼ決まっている**。
  いちばん効くのは人物選び。伸びた人物の近く(同じ雑誌・同じグループ・師弟・ライバル)の人物を続けて出し、関連動画に並ばせる。

### 見えてきた「らしさ」

1. **人生を1行で言い表す「二つ名」**。1つの出来事のニュースではなく、「この人はこういう人だった」が伝わる。
   読んだ人は、その1行の向こうに一人の人生があると感じる(だから25分の生涯解説を見たくなる)。
2. **肩書き・代表作の世界の言葉が入る**: 魔境・名画・直木賞・グラミー・国民的作家・漫画家・名人。
   名前を知らなくても「何をした人か」と「どこが食いちがうか」が1行で分かる。
3. **人物を表す言葉で終わることが多い**: 〜した男・〜な作家・〜の怪人・〜の漫画家・歌声。
4. **食いちがいは人物の芯から取る**: 想像だけで秘境を書いた/勝ちすぎて怪しまれた/着飾る人が裸で描かれた/育てた側が消えた。
   その人の生き方そのものの矛盾なので、動画を見終わったあとも「そういう人だった」と納得できる。
5. **少し皮肉や哀愁があってもいいが、下げない・煽りすぎない**。驚かせるより「へえ、どんな人？」と思わせる。

### らしくない一言(差しかえられやすい)

- **出来事の衝撃だけ**: 「初日で中止、5週間後に死」「肺が7割でフェスに立った」「最高の夜に一人ビリヤード」「3週間の禁酒明けに急死」。
  ニュースの見出しのようで、人物像が見えない。
- **細かすぎる事実・数字だけ**: 「781回負けた最強名人」の数字は、人物像につながるときだけ使う。
- **まとめ・実績・いい話**: 「将棋が命を救った」「無冠から全タイトル独占」。

### 毎回の考え方(型に当てはめて1回で決めない)

1. 台本を通して読み、**「この人はどんな人だったか」を1文で書く**(例: 小栗虫太郎=本と想像だけで世界の秘境と迷宮を書いた男)。
2. **世間の見え方**(肩書き・代表作・いちばん知られている姿)を1つ決める。
3. 台本の中から、その見え方と **食いちがう、その人らしい事実** を5つほど拾う。
4. 「見え方の言葉+食いちがう事実(+人物を表す言葉)」で、一言の候補を10個ほど出す。
5. 次のチェックで3つに絞る:
   - 名前を隠して読んでも、どんな人か浮かぶか(二つ名になっているか)
   - 1つの出来事の見出しになっていないか
   - 動画を最後まで見た人が「たしかにそういう人だった」と思えるか(人物の芯か)
   - 10〜14文字・1行・1秒で読めるか、台本の事実だけか、本人を下げていないか
   - 直前に作った人物のサムネと言い方が同じになっていないか
6. 3つは角度を変える(人物像のひっくり返し・隠れた苦しみや最期・数字の落差)。どれもらしさのチェックは通す。
7. 表の先頭のメモに「この人を1文で」と、落とした候補のうち惜しいものを2〜3個書いておく。
